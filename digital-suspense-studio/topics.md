# Topics

The backlog moved to [`content/topics.md`](content/topics.md).

It now carries the full topic records — pillar, hook, payoff, ending type,
participation angle, freshness note, production needs, weighted score and
lifecycle status — plus the batch-1 production order.

Selection rule: take the highest-scoring topic with status `shortlisted`. Not the
next unticked line. Nothing in this repository is published yet, so no topic is
marked `published`.
